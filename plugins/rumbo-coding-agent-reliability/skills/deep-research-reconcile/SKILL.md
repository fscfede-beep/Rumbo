# Deep Research & Reconcile

Use when multiple sources disagree or current state is unclear.

1. Gather primary evidence first.
2. Rank evidence by authority and freshness.
3. Preserve contradictions instead of overwriting them.
4. Classify claims PROVEN, NOT_PROVEN, UNRESOLVED, HISTORICAL, CANDIDATE, or FAIL_CLOSED.
5. Re-run only checks that can change a decision.
6. Produce one reconciled state and identify its evidence.

Evidence precedence:
1. Fresh authoritative receipt.
2. Exact current-head/object verification.
3. Durable same-scope artifact.
4. Explicit correction with provenance.
5. Historical narrative.

Never use a model assertion, UI state, old PASS, or score as proof of current execution.
