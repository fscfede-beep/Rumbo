RUMBO Coding-Agent Reliability — Privacy Policy

Effective date: 2026-09-02

RUMBO Coding-Agent Reliability is a skills-only plugin. It provides workflow guidance and does not, by itself, connect to external accounts, collect credentials, or execute external actions.

ChatGPT or Codex may process conversation content according to the applicable OpenAI policies and the user's workspace settings.

The plugin does not request passwords, access tokens, API keys, customer secrets, or production credentials.

The plugin does not make claims about customers, revenue, production state, or external execution without corresponding evidence.
